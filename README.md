## 📌 Projetos no Repositório

### ⚔️ 1. <a href="battle-ksr.vercel.app">Sistema de Batalha React (`/react/turn-battle`)</a>
Um jogo de batalha RPG por turnos no estilo *Pedra, Papel e Tesoura*, desenvolvido com React e CSS animado.

* **Destaques & Aprendizados:**
  * Manipulação de estados (`useState`, `useEffect`, `useRef`).
  * Mecânica de danos, cooldown, rondas e estágios progressivos.
  * Feedback sonoro para ações (ataques e vitórias/derrotas).
  * Renderização condicional para telas de transição e animações.
  * Deploy e hospedagem em produção via Vercel.
 
## 🛠️ Tecnologias Utilizadas

* **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
* **Build Tools:** Vite
* **Deploy:** Vercel / GitHub Pages
